## 关于这个博客

这个博客使用 **Astro** 和 **Material Design 3** 构建，具有以下特点：

- 🎨 现代化的设计
- 🚀 超快的加载速度
- 📱 完美的响应式布局
- 🌓 支持明暗主题切换
- 💬 评论系统支持

## 技术栈

博客使用了以下技术：

1. **Astro** - 现代化的静态网站生成器
2. **UnoCSS** - 原子化 CSS 引擎
3. **Material Design 3** - 谷歌最新设计系统
4. **TypeScript** - 类型安全的 JavaScript

## 代码示例

这里是一个简单的 TypeScript 示例：

```typescript
interface BlogPost {
  title: string
  description: string
  publishDate: Date
}

const post: BlogPost = {
  title: '欢迎来到我的博客',
  description: '这是第一篇文章',
  publishDate: new Date('2024-01-15')
}

console.log(\`发布了文章: \${post.title}\`)
```
