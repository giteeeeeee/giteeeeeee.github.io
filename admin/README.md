# 博客本地后台（写文章 / 传图 / 管相册）

一个跑在**你自己电脑上**的网页后台，直接改本地文件，点「一键发布」就 push 到 GitHub 自动上线。参考了 `2846049648.github.io` 的「本地部署 + 一键发布」思路，但针对你的 Hexo + Meow 主题改造，**博客页面、主题、分类完全不动**。

## 和之前方案的区别

| | 本地后台（现在） | Cloudflare 云端后台（已弃用） |
|---|---|---|
| 在哪里跑 | 你自己电脑（localhost） | Cloudflare 云端 |
| 要注册的东西 | 无 | Cloudflare 账号 + GitHub PAT |
| 密码 | 不需要（只有你能访问） | 要设密码 |
| 发文章 | 直接写本地文件 | 走 GitHub API |

## 启动（每次用的时候）

1. 打开一个终端（Git Bash / CMD / PowerShell 都行），进入博客根目录：
   ```bash
   cd "C:\Users\张汶东\giteeeeeee.github.io"
   ```
2. 运行：
   ```bash
   node admin/server.js
   ```
3. 看到「博客后台已启动」后，浏览器打开 **http://localhost:8787**
4. 用完关掉终端窗口即可（后台就停了）。

> 没有任何新依赖要装：Node 你本来就有，`js-yaml` 博客的 `node_modules` 里已经自带。

## 怎么用

- **文章**：左边列表点开编辑，或点「新建文章」。填标题/日期/分类/标签，正文写 Markdown，图片拖进虚线框或 Ctrl+V 粘贴会自动上传并插入。点「保存文章」。
- **相册**：切到「相册」标签，新建/编辑相册，上传照片、设封面、增删照片。点「保存相册」。
- **发布**：改完任何东西后，点右上角 **🚀 一键发布**，填一句说明 → 自动 `git add + commit + push`，GitHub Actions 约 1–2 分钟把改动更新到 `https://giteeeeeee.github.io`。

## 说明 / 注意事项

- 保存只是**写到本地文件**，点「一键发布」才会 push 上线。改完记得发布。
- 后台只监听 `127.0.0.1`，**别人从外面访问不到**，所以不需要登录密码。
- 上传的图片会先被压到最长边 1600px、转成 JPEG，省仓库体积。
- 图片存到 `source/images/`，相册数据写回 `source/_data/albums.yml`（沿用主题 external 模式）。
- 第一次发布会把 `admin/` 这个文件夹也一起提交到仓库（这是正常的，后台代码就该随仓库版本管理）。
- 文件名（网址）建议用英文或数字；留空会自动用 `post-时间戳` 生成。
