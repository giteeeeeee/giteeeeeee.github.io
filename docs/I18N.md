# Internationalization

Reay 默认提供中文和英文界面，并在浏览器中即时切换。当前策略是单一路由、客户端文案切换；它不会为每种语言生成 `/en/*` 或 `/zh/*` 路由。

## 配置

入口：`src/app/config/i18n.config.ts`。

```ts
export const defaultLang = 'zh' as const;

export const languages = {
  en: 'English',
  zh: '中文',
} as const;

export const translations = {
  en: { 'nav.home': 'Home' },
  zh: { 'nav.home': '首页' },
};
```

两种语言的 key 必须一致，TypeScript 会在缺少 key 时报告错误。

## Astro 模板

```astro
---
import { useI18n } from '@features/i18n/lib/i18n';

const { t, currentLang } = useI18n();
---

<h1 data-i18n="page.title.home">{t('page.title.home')}</h1>
```

- `t(key)` 为静态构建提供默认文案。
- `data-i18n` 让客户端在语言切换和页面导航后更新节点。
- 翻译属性时增加 `data-i18n-attr="aria-label"`。
- 带 `data-text` 的元素会更新该属性，供打字机效果读取。

## 个人简介

个人内容维护在 `src/app/config/user.config.ts` 的 `userContent`：

```ts
export const userContent = {
  en: { tagline: 'Developer', bio: '...', greeting: 'Hello', description: '...' },
  zh: { tagline: '开发者', bio: '...', greeting: '你好', description: '...' },
};
```

模板使用以下属性：

```astro
<p data-user-content="bio">{userContent.bio}</p>
```

支持普通字段和点路径，例如 `bio`、`tagline`、`status`、`description` 与 `focus.0`。

## 运行时

- `features/i18n/components/I18nRuntime.astro` 在 `<head>` 早期运行，减少语言闪烁。
- `features/i18n/client/language-toggle.ts` 只负责按钮、持久化和派发事件。
- `shared/client/runtime/client-runtime.ts` 在 Astro 页面切换后重新绑定按钮。
- 当前语言保存在 `localStorage.language`，值为 `zh` 或 `en`。

组件不要重复注册 `languagechange`、`DOMContentLoaded` 或 `astro:after-swap` 监听器。需要新增特殊同步行为时，优先扩展统一运行时。

## 新增导航

1. 在 `src/app/config/navigation.config.ts` 增加路由和 translation key。
2. 在 `translations.en` 与 `translations.zh` 同时增加该 key。
3. 若是新页面标题，增加 `page.title.*`，并在 `I18nRuntime` 的标题映射中登记。
4. 执行 `npm run check`。

## SEO 限制

当前是客户端切换策略，搜索引擎看到的是默认语言的静态 HTML。若需要两种语言分别收录、独立 canonical 和 hreflang，应将 `features.config.ts` 的策略演进为 route-based，并为内容与页面建立语言路由；不要仅依赖客户端切换。
